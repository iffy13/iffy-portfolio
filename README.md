# Iffy Studio portfolio
3D scroll journey portfolio for Samuel Gansallo. Static site, no build.

All web files are in site/, the folder Netlify publishes. Everything else (docs, tests, data, notes) is development only and is never published.

Run: `python3 -m http.server 8000 --directory site` then open http://localhost:8000
Test: `python3 tests/smoke_test.py`
Read first: CLAUDE.md and docs/HANDOFF.md
